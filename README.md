# WCEC 兒童事工：Awana／主日學 報名、家長專區、簽到

家長報名 → 資料進「兒童事工」試算表 → 家長用 Email 確認登入家長專區 → 前台 iPad 用手機末四碼或家庭 QR 卡簽到。
簽退等同工討論接送流程後再加。

## 檔案

| 檔案 | 放哪裡 | 做什麼 |
|---|---|---|
| `apps-script/Code.gs` | 兒童事工試算表 → 擴充功能 → Apps Script | 後端：報名、重複檢查、登入、家長專區、簽到 |
| `register.html` | GitHub Pages | 家長報名表 |
| `parent.html` | GitHub Pages | 家長專區（WCEC App 會嵌入這一頁） |
| `confirm.html` | GitHub Pages | 登入信裡「確認是我」按鈕打開的頁面 |
| `checkin.html` | GitHub Pages | 前台 iPad 簽到站 |
| `common.js`、`style.css`、`config.js` | GitHub Pages | 共用的文字、樣式、後端網址 |
| `demo/` | 只有示範時用 | 在瀏覽器裡模擬試算表和寄信，正式上線可以刪掉 |

## 先試用（示範模式）

`config.js` 的 `API_URL` 留空就是示範模式。它會在瀏覽器裡執行「真正的」後端程式，
只是把 Google 試算表和寄信換成模擬的，資料只存在這台電腦的瀏覽器。

1. 在 Mac 的終端機進到這個資料夾，執行 `python3 -m http.server 8770`
2. 打開 `http://localhost:8770/demo/index.html`：這裡有**模擬信箱**（登入信會出現在這裡）、**試算表內容**、**重設示範資料**
3. 從那頁的連結打開報名表、家長專區、簽到站（密碼 `123456`）

可以試試看：
- **新家庭**：隨便填一份報名表 → 送出後直接進家長專區
- **Email 已經登記過**：報名表填 `daniel.chen@gmail.com` → 會請你寄確認信，不會重複建立
- **同名**：家長填 Daniel Chen、孩子填 Leo Chen，但用新的 Email 和電話 → 會問「這是您的家庭嗎？」
- **續報**：家長專區輸入 `daniel.chen@gmail.com` → 「幫孩子報名」→ 取消 Leo 的「今年參加」，只報 Annie → 簽名送出（模擬試算表的「同意書」會出現簽名圖片）
- **畢業**：`davidlee@outlook.com` → Olivia 顯示已畢業
- **用 Email 登入**：家長專區輸入 `davidlee@outlook.com` → 到模擬信箱按「確認是我」，或輸入信裡的驗證碼
- **App 嵌入樣式**：`parent.html?embed=1`（沒有網頁標題，給 App 用）

> 改了 `apps-script/Code.gs` 之後，要再複製一份到 `demo/Code.gs`，示範模式才會用到新的版本。

## 資料怎麼放

| 工作表 | 一列代表 | 內容 |
|---|---|---|
| 家庭 | 一個家庭 | 家長 First / Last Name、關係、手機、Email、住址（選填）、第二位家長、緊急聯絡人、其他接送人、願意服事、家庭 QR 代碼 |
| 孩子 | 一個孩子（跨學年都是同一列） | First / Last Name、生日、過敏／特殊需求，以及方便同工查看的家長姓名、家長手機 |
| 報名 | 一個孩子在某學年報的一個項目 | 學年、項目（Awana／主日學）、年級、班別、狀態（有效／取消） |
| 同意書 | 一個家庭某學年簽的 Release of Liability | 學年、簽名人、簽名圖片連結、簽名時間、來源 |
| 簽到紀錄 | 一次簽到 | 日期、孩子、接送碼（目前只有 Awana 簽到） |

- 姓名一律用英文 First Name / Last Name；生日必填；年級只到 6 年級（「班別」工作表可以改）。
- 報名表 4 步驟：孩子 → 家長 → 接送與緊急聯絡 → 服事與同意書。每個孩子預設只勾 Awana，主日學要家長自己勾。
- 同意書內容跟紙本報名表一字不改，家長用手指簽名。簽名圖片存在教會 Google Drive 的「WCEC 兒童事工 家長簽名」資料夾（第一次會自動建立，只有教會帳號看得到），試算表只放連結。每個學年要簽一次。

## 新學年續報

1. 新學年開始前，同工在「設定」把**學年**改成新的（例如 `2027-28`），**開放報名**設成 `TRUE`。
2. 選單「兒童事工」→「**寄續報通知給去年的家庭**」：寄信給以前報過、今年還沒報的家庭。
3. 家長打開 App →「家長專區」→ 看到「Awana 2027-28 開放報名了」→ 按「幫孩子報名」：
   - 每個孩子預設勾選「今年參加」和 Awana，主日學要自己勾；年級自動帶「去年的下一級」，可以改。
   - 最下面是今年的同意書，家長簽名後送出。
   - **今年不上的孩子，取消勾選就好**；資料會留著，明年還能再報。
   - 去年 6 年級的孩子顯示「已從 Awana 畢業」，不能勾選。
   - 下面列出聯絡資料讓家長確認，要改可以直接按「修改聯絡資料」。
4. 學期中某個孩子不上了：家長點那個孩子 →「這學年不參加了」，今年的報名改成「取消」，簽到站就不會再出現。只想退出主日學或加報主日學，在同一頁把項目勾掉或勾上就好。

已經登入的家長再打開報名表，會提醒他直接到家長專區，不用重填。

## 家長登入怎麼運作

- **不用帳號密碼**。家長只要輸入報名時的 Email。
- 信裡有「確認是我」按鈕和 6 位數驗證碼。App 畫面會顯示一個兩位數，確認頁也會顯示同一個數字讓家長核對。
- 家長在**任何裝置**按下確認（手機的 Gmail、電腦都可以），App 會自動進入家長專區；也可以回 App 輸入驗證碼。
- 只打開連結**不算**確認，一定要按按鈕。這樣有些 Email 系統先自動打開信裡的連結做安全檢查時，不會誤幫家長登入。
- 登入後同一支手機可以保持登入 365 天（「設定」工作表可以改）。試算表的「登入裝置」只存權杖的雜湊值；把某一列的狀態改成「停用」，那支手機就會被登出。
- **全新家庭**報名完直接登入。**Email 或電話跟現有家庭相同**的，不會自動登入，一定要用原本的 Email 確認，避免別人用你的電話填一份表就看到孩子資料。

## 重複資料檢查

送出報名前，系統會先比對現有資料：

| 比對結果 | 家長看到什麼 |
|---|---|
| Email 或手機相同 | 「您已經登記過了」→ 寄確認信到原本的 Email（只顯示 `ch***@gmail.com`） |
| 家長姓名或孩子姓名相同 | 「這是您的家庭嗎？」列出遮住的家長姓名和 Email → 是我（寄確認信）／都不是我／是我但舊 Email 不用了 |
| 都沒有 | 直接報名 |

- 姓名比對會忽略空白和大小寫（「daniel chen」＝「Daniel Chen」）。
- 選「都不是我」或「舊 Email 不用了」時，還是會建立新家庭，但會在「家庭」的**備註**欄寫下可能重複的家庭編號，請同工檢查、合併。
- 畫面上永遠只顯示遮住的 Email 和姓名，不會把別人的完整資料給陌生人看。

## 同工手動輸入現有家庭

1. 在「家庭」工作表填：**家長 First Name、Last Name、手機、Email**（緊急聯絡人等可以之後請家長自己在家長專區補）。其他欄位留空。
2. 在「孩子」工作表填：**First Name、Last Name、家長手機（手動輸入用）**；要報今年的，再填 **年級（手動輸入用）**。
3. 上方選單「兒童事工」→「**補齊手動輸入的家庭資料**」：自動產生家庭編號、末四碼、QR 代碼、孩子編號，把孩子對到家庭，並幫填了年級的孩子報名今年。有問題（例如沒 Email、手機對不到）會跳出提示。
4. 之後家長在家長專區輸入那個 Email 就能登入。

## 正式上線步驟

1. 建一份新的試算表（例如「兒童事工 Awana」），只分享給兒童事工負責人。不要跟 App 的公告／行事曆試算表放在一起。
2. 擴充功能 → Apps Script，把 `Code.gs` 整份貼上，存檔。重新整理試算表 → 選單「兒童事工」→「初始設定」（第一次會要求授權，包含寄信和 Google Drive 權限；Drive 是存家長簽名用的）。
3. 「設定」工作表：填**簽到站密碼**、**網站網址**（這個網站的 GitHub Pages 網址，結尾要有 `/`），確認學年。
4. Apps Script → 部署 → 新增部署作業 → 網頁應用程式；執行身分「我」、存取權「所有人」。複製網址貼到 `config.js` 的 `API_URL`。
5. 推送到這個 repo，GitHub Pages 會自動更新（正式上線後可以刪掉 `demo` 資料夾）。
6. 前台 iPad：Safari 打開 `checkin.html` → 同工輸入密碼 → 設定 → 輔助使用 → 引導使用模式。

之後改 `Code.gs`：「管理部署作業 → 編輯 → 新版本」，網址才不會變。
寄信用教會 Google Workspace 帳號，每天額度大約 1,500 封，教會規模用不完。

## WCEC App 要做的事（下一步）

家長專區在 App 裡用 `webview_flutter` 嵌入，看起來像 App 的一頁：

- 開 `parent.html?embed=1&lang=zh&theme=light`（語言、深淺色跟著 App）。網頁會藏起自己的標題和語言鍵，標題列和返回鍵由 App 提供。
- **登入權杖存在 iPhone 鑰匙圈**：網頁登入成功會透過 JavaScript 頻道 `WCECApp` 送出 `{"type":"token","token":"…"}`，App 存進鑰匙圈（`flutter_secure_storage`）；下次打開時，網頁先送出 `{"type":"hello"}`，App 從鑰匙圈讀出權杖，執行 `window.__wcecAppToken("…")` 交回（沒有就交空字串；網頁最多等 1.5 秒）。App 端程式在 church_app 的 `lib/screens/kids_parent_screen.dart`。登出時會送出空的 token。
- 載入中、沒網路的畫面由 App 自己顯示；教會網域以外的連結用外部瀏覽器打開。
- App Store 隱私標示和隱私政策要加上：為活動報名與簽到收集姓名、Email、電話（資料存在教會的 Google 帳號）。

## 資料與隱私

- 所有資料只在教會的 Google 試算表，App 本身不保存。
- 簽到站只看到孩子名字、班別、遮住的家長姓名；**過敏資料不會傳到簽到站**。過敏資料只有家長自己（家長專區）和同工（試算表）看得到。
- 家長只能看、改自己家的資料；後端每次都用登入權杖確認是哪個家庭。
- 主要 Email 只能由同工更改；家長可以邀請或移除其他家長的 Email。被移除的 Email，之前的登入也會一起失效。
- 防灌水：報名、寄登入信、邀請都有次數限制；驗證碼錯 5 次就失效；登入信 15 分鐘內有效。
